# Talleres de la ficha de un alumno

La presentación del profesor guía el trabajo. Estos enunciados concretan las prácticas: todas hacen crecer el mismo miniproyecto en parejas.

Empezad por el <a aria-disabled="true">encargo</a> <!-- Enunciado disponible desde Aula Virtual. --> y la [plantilla de documentación](0200_plantilla_documentacion.md).

| Orden | Taller | Resultado que se incorpora |
|---|---|---|
| Preparación | [Arranque guiado](0200_arranque_guiado.md) | Editor, archivos, rutas y repositorio privado compartido. |
| 1 | Ficha válida (enunciado en Aula Virtual) | Cabecera adaptada, corrección de errores y comprobación de la ficha. |
| 2 | <a aria-disabled="true">Intereses y multimedia</a> <!-- Enunciado disponible desde Aula Virtual. --> | Segunda página, imagen, audio y vídeo. |
| 3 | <a aria-disabled="true">Listas y navegación</a> <!-- Enunciado disponible desde Aula Virtual. --> | Tres páginas conectadas, listas y enlaces. |
| 4 | <a aria-disabled="true">El horario del alumno</a> <!-- Enunciado disponible desde Aula Virtual. --> | Tabla de datos en la ficha. |
| 5 | <a aria-disabled="true">Solicitar un cambio</a> <!-- Enunciado disponible desde Aula Virtual. --> | Formulario de solicitud y revisión del conjunto. |

En cada taller se entrega el proyecto acumulado, no cinco sitios distintos. Seguid la [comprobación y entrega común](0200_entrega.md). Solo se exige lo trabajado hasta ese punto; el CSS se incorporará cuando lo indique el profesor al final.

Los cinco enunciados y el encargo se facilitan desde Aula Virtual. Esta tabla muestra el recorrido sin enlazarlos. Los documentos Word, HTML y comprimidos antiguos de esta carpeta no sustituyen estas instrucciones: utilizad únicamente los recursos que enlace cada taller.
