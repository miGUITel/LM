# Recursos de los talleres

[Volver a los talleres](../README.md)

- [Favicon de práctica](favicon.svg): guardadlo como `recursos/imagenes/favicon.svg` en vuestro proyecto.
- [Cabecera para analizar](cabecera.html): abrid el código en VS Code para el taller 1.
- [HTML con errores intencionados](errores.html): ejercicio del taller 2; no es una plantilla correcta.
- [Paquete multimedia del curso](../multimedia.rar): recursos de práctica ya facilitados por el profesor. Descargadlo y extraedlo antes de copiar los archivos. Si vuestro equipo no abre RAR, pedid ayuda al profesor.

El paquete multimedia contiene estos archivos. Copiad solo los que utilicéis y simplificad sus nombres:

| Archivo del paquete | Ubicación propuesta en vuestro proyecto |
|---|---|
| `fotos/El grito.JPG` | `recursos/imagenes/el-grito.jpg` |
| `fotos/La gioconda.jpg` | `recursos/imagenes/la-gioconda.jpg` |
| `panamericano.mp3` | `recursos/audio/panamericano.mp3` |
| `oso.mp4` | `recursos/video/oso.mp4` |

Basta con elegir una de las imágenes. Estos recursos permiten representar, por ejemplo, intereses por el arte, la música y la naturaleza. Anotad en el `README.md` que proceden del paquete multimedia facilitado para la práctica. Si utilizáis otros recursos, anotad su procedencia concreta. No es necesario incorporar el RAR a vuestro proyecto ni generar grabaciones personales.
