# Cierre de HTML: una primera hoja de estilo

**Incorporad esta hoja solo al final, cuando lo indique el profesor.** Antes, el HTML y sus enlaces deben funcionar sin CSS.

1. Descargad [apariencia.css](apariencia.css).
2. Cread `recursos/css/` dentro de vuestro proyecto y guardad allí el archivo.
3. Añadid esta línea en el `head` de cada una de las tres páginas:

```html
<link rel="stylesheet" href="recursos/css/apariencia.css">
```

4. Guardad y actualizad el navegador. Comparad colores, tipografía, controles y contornos de las celdas.
5. Quitad temporalmente el enlace de una página: el contenido y la navegación deben seguir funcionando. Restauradlo después.
6. Anotad qué aporta HTML y qué ha cambiado CSS. Confirmad los cambios y generad un ZIP nuevo si corresponde entregarlo.

La hoja no utiliza columnas, flex, grid, tamaños de caja, márgenes, rellenos ni posicionamiento. Cambia la apariencia. La tipografía puede variar los saltos de línea; no supone una propuesta de maquetación.
