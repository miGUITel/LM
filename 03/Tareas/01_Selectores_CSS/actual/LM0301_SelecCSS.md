# UT3 – Tarea 1: Selectores CSS

Las tareas de esta UT de CSS se alinean con el miniproyecto de la peluquería trabajado en ED. Puedes consultar su memoria si surgen dudas sobre el análisis u otras fases del desarrollo de software. En esta UT trabajaremos la codificación con **HTML y CSS**; los ejemplos representan contenidos del sitio web de la peluquería.

## Qué debes hacer

Dispones de cuatro archivos HTML sobre la peluquería. Crea una **hoja de estilo CSS para cada uno** y aplica los estilos indicados en los ejercicios.

## Requisitos funcionales

- **RF01. Contenido.** Las cuatro páginas deben conservar los textos y las listas de los HTML proporcionados.

## Requisitos no funcionales

- **RNF01. HTML de partida.** Puedes añadir código a los HTML proporcionados, pero **nunca borrar** el contenido existente.
- **RNF02. Hojas de estilo.** Las páginas se deben renderizar sin errores en el navegador mostrando las modificaciones de estilo que has realizado tú.

### Ejercicio 1: [T1.1.html](T1.1.html)

**RNF03.** El formato de **todos los párrafos** debe alternarse de la siguiente manera:

- El primer párrafo, con fondo **gris** y color de letra **rojo**.
- El siguiente, con fondo **azul claro** y color de letra **amarillo oscuro**.
- El siguiente, de nuevo gris y rojo, y así sucesivamente.

En este ejercicio **no puedes utilizar selectores de clase ni de ID**.

### Ejercicio 2: [T1.2.html](T1.2.html)

**RNF04.** Aplica a los párrafos la misma alternancia de colores que en el ejercicio anterior, **utilizando selectores de clase**.

### Ejercicio 3: [T1.3.html](T1.3.html)

**RNF05.** Aplica a los párrafos la misma alternancia de colores, **utilizando selectores de identificador**. Cada ID debe ser único en el documento.

### Ejercicio 4: [T1.4.html](T1.4.html)

**RNF06.** Aplica los siguientes fondos a la lista de servicios:

- Las **categorías de servicios**, con fondo **morado**.
- Los **servicios de cada categoría**, con fondo **rosado**.

En este ejercicio **no puedes utilizar selectores de clase**.

## Qué debes entregar

1. **Los cuatro HTML proporcionados**, con los cambios necesarios, y sus hojas de estilo: `T1.1.css`, `T1.2.css`, `T1.3.css` y `T1.4.css`.
