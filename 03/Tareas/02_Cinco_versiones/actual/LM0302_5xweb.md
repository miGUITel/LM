# UT3 – Tarea 2: Cinco versiones de la web de la peluquería

## Qué debes hacer

La peluquería quiere comparar cinco aspectos visuales de su sitio web. Dispones del archivo [LM0302_plantilla.html](LM0302_plantilla.html). Crea **cinco copias de este HTML** y **una hoja de estilo CSS para cada copia**, siguiendo los estilos indicados más abajo.

## Requisitos funcionales

- **RF01. Contenido común.** Las cinco versiones deben conservar los textos, las listas y los enlaces del HTML proporcionado.
- **RF02. Identificación.** Cada versión debe identificarse en la pestaña del navegador.

## Requisitos no funcionales

- **RNF01. HTML de partida.** Mantén la misma estructura de contenido en las cinco versiones. Solo puedes modificar el título de la pestaña y la configuración necesaria para aplicar las hojas de estilo.
- **RNF02. Resultado.** Las cinco páginas deben renderizarse sin errores en el navegador, mostrando los estilos correspondientes a cada versión.
